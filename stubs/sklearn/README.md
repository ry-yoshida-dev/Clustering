# sklearn stubs

## Overview

Type stubs for the parts of scikit-learn this package calls, because scikit-learn ships no complete types.

## Components

| Component | Description |
|-----------|-------------|
| [cluster/](./cluster/README.md) | `KMeans`, `DBSCAN`, `AgglomerativeClustering`, and `HDBSCAN`. |
| [mixture/](./mixture/README.md) | `GaussianMixture`. |
| [neighbors/](./neighbors/README.md) | `NearestNeighbors`. |
| [exceptions/](./exceptions/README.md) | `NotFittedError`. |
